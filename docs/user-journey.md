# Student Hostel Booking User Journey

## 1. Overview

The user journey describes the experience of a university student using the Student Hostel Booking Mobile Application to find suitable accommodation, compare available options, select a room, confirm a booking, and check booking and payment status.

The journey is designed around the needs identified in the project research and personas, particularly the need for clear hostel information, room availability, pricing, comparison, secure payment interaction, booking confirmation, and status tracking.

## 3. Journey Stages

### Stage 1: Open the Application

The student opens the mobile application to begin searching for hostel accommodation.

### Stage 2: Login or Register

A returning student logs in. A new student can register before accessing the main application functions.

### Stage 3: Access the Home Screen

After login, the student reaches the home screen where the main hostel search and browsing functions are available.

### Stage 4: Search and Filter Hostels

The student browses available hostels or uses search and filtering functions to narrow down the accommodation options.

### Stage 5: Select a Hostel

The student selects a hostel from the available hostel list and opens its details.

### Stage 6: Review Hostel Information

The student reviews information such as hostel photographs, location, facilities, room types, prices, and room availability.

### Stage 7: Compare Room Options

The student compares available accommodation options to decide which room best meets their needs.

### Stage 8: Select a Room

The student selects a preferred available room and proceeds to the booking process.

### Stage 9: Review Booking Details

Before confirming, the student reviews the selected hostel, room, price, and other relevant booking information.

### Stage 10: Confirm Booking

The student confirms the booking after reviewing the information.

### Stage 11: Payment

The student proceeds through the payment step represented by the prototype.

### Stage 12: Receive Booking Confirmation

The application provides feedback confirming that the booking has been submitted successfully.

### Stage 13: Check Booking and Payment Status

The student accesses their booking to view the current booking status and payment status.

## 4. User Journey Summary

| Stage | Student Action | Application Response |
|---|---|---|
| 1 | Open app | Displays login/register |
| 2 | Login/register | Provides access to the application |
| 3 | Open home | Displays hostel options and search functions |
| 4 | Search/filter | Displays relevant hostel options |
| 5 | Select hostel | Opens hostel details |
| 6 | Review details | Displays photos, location, facilities, rooms, prices and availability |
| 7 | Compare options | Supports comparison of available accommodation |
| 8 | Select room | Opens booking process |
| 9 | Review booking | Displays selected booking information |
| 10 | Confirm booking | Processes the booking interaction |
| 11 | Proceed to payment | Displays payment step |
| 12 | Complete booking | Displays booking confirmation |
| 13 | Check status | Displays booking and payment status |

## 5. Expected User Outcome

At the end of the journey, the student should be able to identify a suitable hostel and room, complete the booking process through the prototype, receive clear confirmation, and determine the current booking and payment status.
