# Project Objectives

## Main Objective

To design a mobile application prototype that simplifies the process of searching, comparing, and booking university hostel accommodation.

## Specific Objectives

1. To design a mobile application for finding university hostels.
2. To allow students to view available hostel rooms and accommodation details.
3. To allow students to compare accommodation options based on price, facilities, and availability.
4. To allow students to select and book suitable hostel rooms.
5. To allow students to view booking and payment status through the application.
