# Usability Testing Tasks

## Task 1 — Find an Affordable Hostel

Imagine that you are a student looking for accommodation for the coming semester.

Use the application to find a suitable hostel that is within your preferred budget.

### What We Observe

- Can the user find the hostel search feature?
- Can the user understand the hostel information?
- Can the user identify a suitable hostel?
- Does the user know what to do next?

---

## Task 2 — Search Using Filters

Use the hostel search and filtering options to find a hostel based on your preferred location, price range, and room type.

### What We Observe

- Does the user understand the Location option?
- Does the user understand the Price Range option?
- Does the user understand the Room Type option?
- Can the user apply the filters successfully?
- Does the user understand the resulting hostel list?

---

## Task 3 — Compare Available Rooms

Imagine that you have found a suitable hostel with more than one available room.

Use the application to compare the available room options and decide which room you would prefer.

### What We Observe

- Can the user locate the room comparison feature?
- Does the user understand the information presented?
- Can the user distinguish between the available rooms?
- Can the user make a decision based on the information provided?

---

## Task 4 — Proceed With a Booking

Select a suitable room and proceed through the booking process.

### What We Observe

- Can the user identify where to start the booking?
- Does the user understand the booking process?
- Does the user know what action to take next?
- Is the booking information clear?
- Does the user receive clear feedback after completing an action?

---

## Task 5 — Check Booking and Payment Status

Imagine that you have already made a hostel booking.

Use the application to locate your booking and determine its current booking and payment status.

### What We Observe

- Can the user find the Bookings section?
- Can the user locate the relevant booking?
- Can the user identify the booking status?
- Can the user identify the payment status?
- Does the user understand whether the booking is complete?
