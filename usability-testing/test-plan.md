# Usability Testing Plan

## 1. Purpose

The purpose of this usability test is to evaluate the usability,
navigation, clarity and effectiveness of the Student Hostel Booking
Application prototype.

The testing will identify usability problems experienced by
representative student users and provide evidence for improving
the prototype.

## 2. Participants

The usability test will involve at least five representative
student users who are potential users of the Student Hostel
Booking Application.

Participants will be identified as User 1, User 2, User 3,
User 4 and User 5 to maintain anonymity.

## 3. Testing Method

Participants will interact with the Balsamiq prototype and
complete realistic hostel-booking tasks.

The researcher will observe how participants navigate the
prototype without providing unnecessary assistance.

The following will be recorded:

- Task completion
- Errors
- Navigation difficulties
- Confusion
- Time taken where practical
- User comments
- Suggestions for improvement

## 4. Testing Environment

The test will be conducted using the Balsamiq prototype.
Each participant will complete the same set of tasks.

## 5. Testing Procedure

1. Introduce the purpose of the test to the participant.
2. Explain that the prototype, rather than the participant,
   is being evaluated.
3. Give the participant the first task.
4. Allow the participant to attempt the task independently.
5. Observe their actions and difficulties.
6. Record the result.
7. Repeat for all tasks.
8. Ask the participant for general feedback at the end.

## 6. Expected Outcome

The testing is expected to identify usability problems related
to navigation, search, hostel selection, booking and feedback.

The findings will be analyzed and used to improve the prototype.
