Member 5 — Prototype Linking + HCI
Overview

Member 5 is responsible for connecting the wireframes created by Member 4 into an interactive prototype using Balsamiq.

The main tasks are:

Link buttons and navigation between screens.
Make sure the screens work together logically.
Create at least three complete mobile interaction scenarios.
Apply basic HCI principles such as clear navigation, consistent buttons, readable text, and understandable feedback.
Document the interaction scenarios.

HCI Considerations

The prototype should follow basic HCI principles:

Clear navigation — users should know where to go next.
Consistent buttons — similar actions should look and behave consistently.
Readable text — information should be easy to read on mobile screens.
Good touch targets — buttons and interactive elements should be easy to tap.
Action feedback — important actions should provide visible feedback.
Understandable icons — icons should have clear meanings.
Consistent terminology — use the same names for features throughout the app.
Logical screen order — screens should follow a natural user flow.
