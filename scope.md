# Project Scope

## In Scope

- User registration and login screens.
- Viewing available hostels and room listings.
- Searching and filtering hostel accommodation.
- Viewing hostel details, room information, pricing, and facilities.
- Comparing available accommodation options.
- Selecting and booking hostel rooms.
- Viewing booking confirmation details.
- Viewing booking and payment status.
- Mobile user interface prototypes created using Balsamiq.

## Out of Scope

- Real payment gateway integration.
- Actual hostel management operations.
- Integration with university databases.
- Real-time room allocation systems.
- GPS navigation and mapping services.
- Full system development and deployment.

## Target Users

The primary users of the application are university students seeking hostel accommodation near campus.
